# Oldagram

A simple Instagram-inspired feed built as a solo project for the Scrimba Fullstack Developer Path.

## Features

- Dynamically renders posts from JavaScript data
- Displays user information, post images, likes, and comments
- Increases the like count when a post is double-clicked
- Hover effects on post action icons
- Semantic and accessible HTML structure
- Layout based on a Figma design

## Built With

- HTML
- CSS
- JavaScript
- Vite

## Running Locally

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## About the Project

This project was created as part of the Scrimba Fullstack Developer Path to practice HTML and CSS fundamentals, working from a Figma design, rendering data with JavaScript, and handling user interactions with event listeners.
